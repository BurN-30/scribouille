# Corrections automatiques
#
# Une règle par ligne, au format :
#     forme erronée => forme correcte
#
# Appliquées au texte final, après la transcription. La casse est ignorée
# et seuls les mots entiers sont remplacés : la règle « git » ne touchera
# donc pas « digital ». Les expressions de plusieurs mots fonctionnent.
#
# À nourrir au fil de l'eau : quand une transcription écorche toujours le
# même mot, ajoutez la règle ici et le problème ne reviendra plus.
#
# Les lignes vides et celles commençant par « # » sont ignorées.
#
# Les exemples ci-dessous sont en commentaire : ils montrent la forme
# attendue sans rien modifier dans vos transcriptions. Retirez le « # »
# devant une ligne pour l'activer, ou écrivez directement vos règles.

# --- Noms propres régulièrement massacrés

# mon entreprise => MonEntreprise
